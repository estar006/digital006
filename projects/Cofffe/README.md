
# ☕ Swiss Cafe Website

## About the Project

Swiss Cafe is a responsive coffee shop website designed to showcase a cafe's menu, products, and services. The website provides visitors with an attractive and user-friendly experience where they can explore the cafe, browse available drinks and food, and navigate through different sections.

## ✨ Features

- Responsive website design.
- Home page with an attractive hero section.
- Navigation menu for easy browsing.
- Menu section showcasing coffee and other products.
- Order page for customers.
- Clean and user-friendly interface.
- Attractive images and styling.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layouts.
- JavaScript – Interactive functionality.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR-REPOSITORY-LINK
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
